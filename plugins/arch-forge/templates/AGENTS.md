## How to work

- Add features from the inside out: domain → usecase / port → adapter → wiring → tests
- Before changing layer, module or service boundaries, or the framework or major libraries, write an ADR and get the user's approval
- Before reporting completion, run the tests and arch-lint and check the results. Write "not verified" for any verification you could not run
- Never commit secrets. Read settings from environment variables
- Treat an unset or unknown `APP_ENV` as production. In-memory implementations and simplified modes only with `APP_ENV=local`
